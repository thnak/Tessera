# Open questions register and decisions

Every normative spec and design note keeps its own `Open questions` section, because the question belongs next to the contract it affects. This register is the single index: it links each question to its source, records the decision (or an explicit deferral with a trigger), and highlights what the next implementation round can start on without waiting for an owner decision.

Status legend: **resolved** means a V1 decision exists and is recorded here; **deferred** means the decision needs a platform/vendor choice, owner product input, or a measurement, and the trigger says when to revisit it.
