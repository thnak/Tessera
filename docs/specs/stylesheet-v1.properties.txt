# Machine-readable form of the V1 compatibility matrix in stylesheet-v1.md section 11 (issue #250).
#
# The prose table in section 11 says what each area means; this file says exactly which property
# names V1 promises. The `property_registry_matrix` ctest keeps the two in sync in both directions,
# so a property cannot be promised here and silently dropped by the engine, and a property cannot be
# registered without this file saying so. Change the registry and this file in the same commit.
#
# Format: one entry per line, `<kind> <name> <section 11 row>`, whitespace separated.
#   longhand   PropertyRegistry::find() returns it: the cascade stores it and gives it an initial
#              value (an empty initial means "absent until declared", as for the logical longhands).
#   shorthand  PropertyRegistry::longhands() returns its expansion, and every longhand it names is
#              itself registered.
#   external   PropertyRegistry::find() returns it, but the grammar and expansion live in another
#              module (named in the comment above the entry); the registry only has to accept the
#              name so the cascade stores it and @supports answers true.
# Blank lines and `#` comments are ignored. The row is the section 11 table row, lowercased with
# spaces as hyphens; it is what a failure message names, so a reader lands on the right paragraph.
