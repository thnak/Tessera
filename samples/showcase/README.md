# showcase

The Studio's first sample: what a React + Vite developer would write, written the same way. Plain
HTML-style elements, a global stylesheet next to a CSS module, design tokens, hover / focus / active
states, a responsive layout, a conditional child, controlled input and state.

Open this folder in the Studio (`tessera.json` names `Showcase.tsx` as the entry). Its browser twin
is `tools/parity/showcase.html`; keep the two structures identical.
