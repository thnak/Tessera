Input script

One step per line: click <automationId>. Clicking a node below appends its id. Each click is dispatched through the engine's own input router — hit test, pointer capture, click synthesis, capture/target/bubble — and the handler it reaches is the handler's TSX preview body, run by the IR evaluator. The developer's C++ is not in this module and is never executed.
